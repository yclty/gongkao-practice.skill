# Start Experience v0.8

## 目标

用户不需要先理解 Scheduler、Mastery、SRS，也不需要先估算“我有几分钟”。

默认体验：

```text
打开 Project
   ↓
说“开始练习”
   ↓
系统直接给第一题
   ↓
连续做
   ↓
任何时候都可以暂停
```

时间预算是可选增强项，不是主入口。

## 首次初始化后的入口

初始化完成后不要输出一长串功能说明。

只给一个明确主动作和三个次动作：

```text
准备好了。

[直接开始]   ← 推荐
系统会边练边建立你的能力画像，随时可以暂停。

[选一个专项]
[导入已有错题/记录]
[看看怎么用]
```

如果宿主没有按钮，用同样顺序的简短文字选项。

## 日常返回入口

### 有未完成训练

```text
上次还有训练没完成。

[继续上次]   ← 默认
[重新开始]
[换个专项]
```

### 没有未完成训练

```text
今天继续练。

[直接开始]   ← 默认
先处理到期复习，再练当前最值得加强的内容。

[只复习错题]
[专项训练]
[按时间训练]
```

## 默认“直接开始”

用户说以下任一表达，都不要追问时间、题量、难度：

- 开始
- 开始练习
- 今天练一下
- 刷题
- 来几道
- 继续练

系统直接：

1. 读取当前 Project state；
2. 如有 unfinished session，优先继续；
3. 如有到期复习，先进入到期复习；
4. 否则进入当前高优先级弱项；
5. 数据不足时进入 baseline coverage；
6. 拉取一个 3 题原子批次；
7. 显示第一题。

## 原子批次

默认每次只规划 3 题。

原因：

- 足够形成连续感；
- 用户突然有事时损失很小；
- 不需要每题都重新调度；
- 完成后可快速根据新数据重新判断下一批。

3 题完成后：

```text
[继续刷]   ← 默认
[换个专项]
[结束并总结]
```

如果用户持续选择“继续刷”，系统可以连续工作很多批次；用户不需要提前声明总时长。

## 暂停

答题卡在题目页和解析页都显示：

`暂停`

暂停行为：

1. 停止当前题计时；
2. 未提交的当前题不算错误；
3. 已完成题生成 attempt events；
4. 返回 `unfinished_session`；
5. 当前 Project 保存新 state；
6. 下次说“继续上次”时优先恢复。

用户没有点击暂停而直接离开时，也不要把未提交题判错；下一次如果宿主仍能识别 unfinished session，则继续，否则按新一批训练重新调度。

## 时间模式

仅在用户主动表达时启用：

- 我只有 5 分钟
- 练 10 分钟
- 午休还剩 20 分钟

时间模式仍然允许提前暂停，不要求必须完成计划题量。

## 专项模式

用户说：

- 专练资料分析
- 今天练判断推理
- 只练两期比重

直接进入 focus 模式，不再追问时间。

如果用户同时指定时间：

`10分钟资料分析`

则 focus + timeboxed 同时生效。

## 模考例外

以下场景可以要求或使用明确时长/题量：

- 全真模考
- 套卷
- 定时速度训练
- 用户明确要求固定题数

这是“开始练习”的例外，不影响日常默认 start-first。

## 新用户认知原则

用户只需要逐步知道 4 件事：

1. **开始练习**：系统自己安排；
2. **暂停**：有事就停；
3. **继续上次**：回来接着做；
4. **专项训练**：想练什么可以直接说。

能力画像、SRS、Mastery、Priority Score 都是后台机制，不应成为首次使用说明。
