# 统一错因分类

为了让长期数据可比较，所有训练统一使用以下错误代码。

| code | 类型 | 判定标准 |
|---|---|---|
| K | 知识不会 | 缺少必要概念、公式、政策或事实知识 |
| M | 方法不会 | 知道考点，但不会有效解法或解题框架 |
| U | 理解错误 | 对材料、论证关系、概念含义理解偏差 |
| R | 审题错误 | 漏看否定词、限定条件、单位、设问方向等 |
| C | 计算错误 | 解题路径正确，但运算或数据处理出错 |
| D | 干扰项误判 | 被典型干扰项吸引，排除逻辑不稳定 |
| T | 时间不足 | 本可做对，但因时间管理未完成 |
| G | 蒙题 | 无有效推理或依据，主要依靠猜测 |
| S | 速度不足 | 方法与答案正确，但耗时明显高于目标 |

## 使用规则

1. 每道错题优先标记一个“主错因”，必要时增加一个“次错因”。
2. 不允许把所有错题都归为“粗心”；必须落到可训练的具体类别。
3. 连续 3 次同 subtype 出现相同错因时，应提升该弱点的训练优先级。
4. 答对但耗时明显过长，可标记 `S`，仍进入速度优化训练。
5. AI 自拟题与真实题的表现分开统计，真实题优先用于能力评估。
