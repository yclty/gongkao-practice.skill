# Study Route & Scene Launcher v0.9

## 目标

用户每次打开系统，不应该只看到“开始练习”。

系统要主动回答三个问题：

1. **现在适合怎么学？**
2. **我的长期路线走到哪里了？**
3. **当前题库和个人画像是否正常？**

## 学习场景

### Deep

适用于：
- 晚上
- 周末
- 明确说“我现在有整块时间”
- 用户自定义的非工作时段

推荐入口：

- 继续学习路线
- 集中学一个章节
- 做一套 20 题
- 做一套真题试卷
- 随手刷几题

### Fragmented

适用于：
- 工作时段
- 通勤 / 排队 / 等人
- 明确说“碎片时间”
- 明确可用时间 <= 10 分钟

推荐入口：

- 3 题快刷
- 到期错题
- 路线继续一小段

不主动安排完整套题。

### Neutral

无法判断场景时：

- 系统推荐
- 继续路线
- 集中章节
- 做一套
- 碎片刷题

不要求用户先配置。

## 启动卡片语义

Deep 示例：

```text
现在更适合做一段完整训练。

路线进度：资料分析 → 当前：增长率
到期复习：2 项
真题库：已加载 12,843 道可作答题 / 126 套完整试卷

推荐：
[继续路线 · 资料分析-增长率]

还可以：
[集中学一个章节]
[做一套20题]
[做一套真题试卷]
[只想随手刷几题]
```

Fragmented 示例：

```text
现在按碎片时间来，不给你安排长任务。

到期复习：2 项

[先做3题]
[到期错题]
[路线继续]
```

## 数据状态必须分开

禁止统一说“缺乏数据”。

必须区分：

### PERSONAL_PROFILE_BUILDING

含义：用户作答样本少。

提示：

```text
你的个人画像还在建立中，但不影响直接训练。
```

### QUESTION_BANK_NOT_CONFIGURED

含义：QuestionProvider 没有接入当前运行时。

提示：

```text
真题库当前没有接入运行时。
这不是你的个人数据不足。
```

### QUESTION_BANK_READY

提示题数 / 套卷数量。

### QUESTION_FILTER_EMPTY

题库已加载，但当前筛选无题。

提示：

```text
题库已经正常加载，只是当前章节/年份筛选没有匹配题目。
```

## 学习路线

学习路线属于当前 Project。

示例：

```text
路线：2027 国考

1. 资料分析             ← 当前
2. 判断推理
3. 言语理解与表达
4. 数量关系
5. 政治理论
6. 常识判断
```

可以细化：

```text
1. 资料分析 · 增长率
2. 资料分析 · 比重
3. 资料分析 · 两期比重
4. 判断推理 · 加强削弱
...
```

用户可以说：

- 制定我的学习路线
- 先资料分析，再判断推理
- 晚上按路线学，工作时间碎片刷
- 把数量关系放后面
- 这个章节先跳过

若 `configure_project_study_route` 可用，使用工具生成新 state 并保存回当前 Project。

## 模式定义

### quick

默认 3 题。

### route

当前路线步骤，默认 10 题。

### chapter

指定 module/subtype，默认 10 题。

### set

跨模块 20 题。

### paper

从 QuestionProvider 选择完整可交互的真实导入试卷。

### review

到期复习优先。

所有模式都允许中途暂停。

## 题库策略

- 先调用 `get_question_bank_status`
- 真题库可用时优先 `official_real | platform_import`
- 题库未配置时明确告知
- 只有用户接受或无真题运行时才使用 AI 变式题
- AI 题必须标记 `ai_variant`

## 非工作时段推断

如果用户未配置工作时间，默认只做轻量启发：

- 周末 → deep
- < 08:00 → deep
- 09:00–18:00 → fragmented
- >= 18:00 → deep

这是推荐，不是强制。

用户自定义 work_hours 后，以 Project 设置为准。
