# UI Contract v0.3

## 目标体验

用户只需要告诉系统“现在有多少时间”，剩余训练决策由系统完成。

普通选择题理想操作成本：**一道题一次点击**。

## Surface

### inline_card
适合：
- 5～20 分钟微训练
- 普通选择题
- 错题复习

显示：
- 模块 / subtype
- 进度
- 题干
- A/B/C/D
- 轻量反馈

### fullscreen
适合：
- 资料分析长材料
- 表格/图片
- 多题共用材料
- 模拟考试

### summary_card
训练结束显示：
- 题量
- 正确率
- 有效用时
- 主要错因
- 本轮 mastery 变化
- 下一训练重点

### ability_view
展示模块和 subtype 掌握度，不把长表格作为默认体验。

## 原则

- UI 临时状态与长期学习状态分离。
- 计时由界面自动完成，暂停时间剔除。
- 默认解析短，详细解析按需展开。
- AI 错因允许用户一键修正。
- UI 不具备某能力时，必须退化到文字模式继续训练。
