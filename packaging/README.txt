考公上岸 Coach 1.0.0（Windows x64）

1. 将 ZIP 完整解压到任意普通目录，支持中文和空格路径。
2. 双击 install.cmd。不需要管理员、Node、Python、npm 或云服务器。
   已安装 Codex Desktop 时，它会注册并安装本地 Plugin。
   没有 Codex 时仍可使用本地答题网页；AI 教学需要 Codex Desktop。
3. 在网页建立自己的学习档案。以后点桌面 Gongkao Coach 继续。
4. AI 入口：在 Codex 新聊天启用“考公上岸 Coach”，在网页“档案与备份”
   复制“AI 聊天入口”粘贴到聊天。说“开始练习”“继续上次”“专练资料分析”。
5. 每题正式提交自动保存。关闭网页或聊天不会删除记录。严格模拟整卷提交。

多人使用
给别人发送原始公共 ZIP，每个人在自己的电脑/系统账户安装并建立档案。
同一个系统账户可选择多个档案；需要保密请分别使用操作系统账户。
网页和 AI 共用 binding 指向的档案，聊天不能自动猜测使用者。

长期保留
个人数据默认位于 %LOCALAPPDATA%\GongkaoCoach\data。
安装源、公共包、Codex 插件缓存均与个人数据分开。
升级：解压新版再运行 install.cmd，升级前保存备份，保留已有档案。
换机：网页导出个人 .gkbackup，到另一台电脑网页导入，建立新档案。
旧 0.9 Project JSON 在网页专用入口导入，保留历史快照。
uninstall.cmd 断开插件并停止服务，默认保留公共文件和个人记录。

独立网页提供训练、报告和备份；AI 教学运行于桌面聊天。
安装包没有离线大模型，AI 仍使用宿主账户与联网能力。
本版不包含独立网页 AI 聊天、可靠申论自动评分或自动跨机器同步。
题库为第三方导入，缺题/缺图/答案无效的题和卷不会进入完整模拟入口。
不承诺考试录用结果。
